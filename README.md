# Student Task Application - Student 2

## Project Description

Student Task Manager is a simple web application developed as a pair-based Git and GitHub project.

The application is designed to help users manage their tasks. Users can add tasks, view tasks, mark tasks as completed, delete tasks, and search for tasks.

The main purpose of this project is to demonstrate the use of Git and GitHub in a collaborative software development workflow.

## Git Workflow

The project follows a collaborative Git and GitHub workflow.

The main workflow used in this project was:

1. Create the project
2. Initialize Git
3. Create commits
4. Create GitHub repository
5. Create feature branches
6. Develop features
7. Push branches to GitHub
8. Create GitHub Issues
9. Create Pull Requests
10. Perform code reviews
11. Merge Pull Requests
12. Create and resolve a merge conflict
13. Demonstrate Git recovery commands
14. Create a Git tag
15. Create a GitHub release
